# NG image notes

## Overview
This folder contains NG-specific pi-gen configuration and one consolidated NG stage at `ng/stage`.

## Quick build
Build with upstream docker builder (no NG wrapper):

```bash
./build-docker.sh -c ng/configs/ng-ato-panel
```

Other targets:

```bash
./build-docker.sh -c ng/configs/ng-ato-main
./build-docker.sh -c ng/configs/ng-cast
```

`PRESERVE_CONTAINER` is optional.
Use `PRESERVE_CONTAINER=1` only when you want to inspect the container or continue a failed build.

## Differences vs upstream pi-gen
- Uses `STAGE_LIST="stage0 stage1 stage2 ng/stage"` in NG configs.
- Replaces legacy NG multi-stage layout with one consolidated stage at `ng/stage`.
- Uses netplan config files generated by NG scripts:
  - `/etc/netplan/10_ng-eth0.yaml`
  - `/etc/netplan/11_ng-wifi.yaml`
- Uses built-in hostname handling (`TARGET_HOSTNAME`) rather than custom hostname stage scripts.
- Cloud-init is disabled in NG configs (`ENABLE_CLOUD_INIT="0"`).

## What NG stage sets up
`ng/stage` executes these steps:
- `00-packages`: installs `wget` and `curl`
- `01-netbird-install`: installs NetBird client and stops service in image build context
- `02-netbird-register`: creates and enables first-boot registration service only if `NG_NETBIRD_SETUP_KEY` is non-empty
- `03-network-config/00-init.sh`: ensures `/etc/netplan` exists
- `03-network-config/01-wifi.sh`: writes `11_ng-wifi.yaml` when Wi-Fi is enabled, removes it otherwise
- `03-network-config/02-eth0.sh`: writes `10_ng-eth0.yaml` for DHCP or static config, removes it if Ethernet is disabled

Image export is enabled by `ng/stage/EXPORT_IMAGE`.
